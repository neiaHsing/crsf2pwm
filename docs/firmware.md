# 固件配置

以下是当前源码的配置，不代表所有外设已在 PY32F002A 上验证。

| 功能 | 当前引脚或设置 |
| --- | --- |
| 状态 LED | PB2，`LED_INVERTED=1`，低电平亮 |
| CRSF 接收 / 发送（MCU 视角） | PF1 / PA0 |
| 调试串口 | 使用核心默认的 `Serial`，115200 baud |
| 电池 ADC | PA7 |
| PWM 1–4 | PA5、PA6、PB0、PB1 |
| PWM 5–8 | PB3、PF0、PA1、PB6 |
| CRSF 波特率 | 420000 |
| PWM 频率 | 50 Hz |

引脚与分压比例在 `firmware/crsf2pwm/target.h`。通道映射、失控值、频率与电压修正系数在 `crsf2pwm.ino`。低电平 LED 设置已存在于整理前的工作区，予以保留。

完整程序中 LED 在收到连接事件后亮起、断开后熄灭；LED 示例则启动后一直亮。完整程序只在收到通道数据后初始化 PWM 输出。

当前失控配置：通道 1–4 为 1500、1500、988、1500 µs；通道 5–7 保持上一值；通道 8 停止脉冲。电机油门通道必须根据实际用途确认，不能从通道编号推断。

## 待验证事项

- 引脚复用、定时器通道是否支持 8 路独立输出，特别是更换 MCU 后的外设差异。
- PB6 同时涉及 BOOT0，需结合最终硬件确认 PWM8 的接法。
- 电压计算目前采用 5 V 参考值、`VBAT_R1=1000`、`VBAT_R2=100`（比例 10:1）和 `VBAT_SCALE=1.1`；实际电阻值、参考电压及 CRSF 回传单位需实测校准。
- 完整固件的时序、串口接收、电压回传和失控行为还需实物验证。
- `median.h` 中 `clear()` 保留了原有 `sizoe` 拼写问题；当前路径未调用该函数，后续使用前需修复。此次目录整理未修改业务逻辑。
