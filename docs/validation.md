# 验证记录

## 目录整理后的构建（2026-09-25）

使用 Arduino CLI 1.5.1、AirMCU 0.6.4、ARM GCC 14.2.1，复用本机 CMSIS 5.7.0；时钟显式设为 HSI 8 MHz。

| 配置 | 结果 |
| --- | --- |
| `firmware` | 成功；程序 25,204 字节，全局变量 2,176 字节 |
| `led` | 成功；程序 10,748 字节，全局变量 1,116 字节 |
| `py32-check` | 按预期失败；Flash 超出 4,952 字节，RAM 超出 640 字节 |

脚本语法检查通过，错误参数会输出用法并退出。本次没有连接或重新烧录实物。官方包默认使用的 GCC 13.2.1 与本机工具链不同，编译体积可能略有差异。

CLI 的容量统计、ELF 的加载段、烧录页总量并非同一计数方式。RAM 链接溢出包含链接脚本预留的堆栈，不能仅用全局变量大小判断能否放下。

上述数字是历史工具日志，不是本次结构整理后的重新测量值。历史 LED 示例烧录后的 GPIO 读回步骤没有完成；更早的 HAL LED 实验曾读回 PB2 输出状态，但那不能替代 Arduino 示例的验证。LED 实物观察及完整 CRSF 功能测试由作者补充。
